# 走水丸

横須賀・大津港〜走水周辺の小型ボート釣り向けAndroidアプリです。

## 開く・実行する

1. Android Studioでこのフォルダーを開く
2. Gradle Syncを実行
3. 位置情報を利用できる実機またはエミュレーターで `app` を実行

パッケージ名は `com.digihori.hashirimizumaru`、最小AndroidバージョンはAndroid 8.0
（API 26）です。

## 実装済み

- MapLibreによる対象地域限定地図、OpenSeaMapシーマーク切替
- 海しるAPIによる20m・50m・100m等深線表示、対象海域抽出、端末キャッシュ
- GPS現在地、省電力（15秒・30m）/高精度モード
- Roomによるウェイポイントの登録・編集・削除・並べ替え（自動採番名、座標、メモ）
- 度・分／十進表記に対応した座標入力、地図長押し登録、一覧からの地図フォーカス
- 地図上のウェイポイント名表示、ナビ目的地の強調表示
- 目的地の距離・方位表示、30m以内で振動・通知・ナビ自動終了
- フォアグラウンドサービスによる画面OFF・バックグラウンドでのGPS航跡記録と到着判定
- 釣行単位の航跡管理、地図表示、編集、削除
- EXIF日時・位置を使用する写真中心の釣果記録、編集、削除、地図表示
- 横須賀の簡易タイドグラフ（潮回り、次の満干潮、潮位変化）
- ポイント、航跡、釣果、写真の手動バックアップ・復元
- 初回免責同意、プライバシーポリシー、バージョン情報

## 配信前に設定が必要な項目

- `local.properties` に海しるAPIの個別サブスクリプションキーを
  `MSIL_SUBSCRIPTION_KEY=...` として設定する（リポジトリには登録しない）
- 署名付きリリースでは、リポジトリ外の `keystore.properties` に署名情報を設定する

20m・50m・100m等深線は初回表示時に海しるAPIから取得し、大津港〜走水の対象範囲だけを端末へ保存します。
通常の地図タイルとシーマークはMapLibreの通常キャッシュのみを使用し、対象範囲の一括事前
ダウンロード機能は提供しません。

現在の等深線取得は海しるAPI V2を使用しています。V2提供終了前に、GeoJSONキャッシュとの
互換性を維持しながらV3 FeatureServiceへ移行します。
