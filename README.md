# 走水丸

横須賀・大津港〜走水周辺の小型ボート釣り向けAndroidアプリです。

## 開く・実行する

1. Android Studioでこのフォルダーを開く
2. Gradle Syncを実行
3. 位置情報を利用できる実機またはエミュレーターで `app` を実行

パッケージ名は `tk.horiuchi.hashirimizumaru`、最小AndroidバージョンはAndroid 8.0
（API 26）です。

## 実装済み

- MapLibreによる対象地域限定地図、OpenSeaMapシーマーク切替
- 海しるAPIによる20m・50m・100m等深線表示、対象海域抽出、端末キャッシュ
- GPS現在地、省電力（15秒・30m）/高精度モード
- Roomによるウェイポイントの登録・編集・削除（名前・座標・メモ）
- 地図上のウェイポイント名表示、長押し地点の登録、一覧からの地図フォーカス、ナビ目的地の強調表示
- 目的地の距離・方位表示、30m以内で振動・通知・ナビ自動終了
- フォアグラウンドサービスによる画面OFF・バックグラウンドでのGPS航跡記録と到着判定
- 釣行単位の航跡管理、地図表示、編集、削除
- EXIF日時・位置を使用する写真中心の釣果記録、編集、削除
- 初回免責同意、プライバシーポリシー、バージョン情報

## 配信前に設定が必要な項目

- `app/build.gradle.kts` の `PRIVACY_POLICY_URL` を実際のGitHub上の
  `PRIVACY.ja.md` URLに合わせる
- 公開時は海しるAPIの個別サブスクリプションキーへ切り替える

20m・50m・100m等深線は初回表示時に海しるAPIから取得し、大津港〜走水の対象範囲だけを端末へ保存します。
通常の地図タイルとシーマークはMapLibreの通常キャッシュのみを使用し、対象範囲の一括事前
ダウンロード機能は提供しません。
